## Sequence and configuration

Continue AP-001 and Annex M integration first; then independent event states, reservations/readiness, participants/sessions, publication, public registration and provider sandbox payment/refund reconciliation. Named reviewers, publisher/safety authority, fee/hold/refund/retention policy, website receiver contract and official gateway contract remain prerequisites. The KCC website CMS remains a separate project; it must not create a second authoritative registration roster. Official MIS/SSO activation is still pending.
